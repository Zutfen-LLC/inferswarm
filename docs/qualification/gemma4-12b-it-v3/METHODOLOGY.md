## 3. Canonical-prefix / teacher-forced execution contract

Every validity-bearing numerical comparison uses an identical canonical
reference prefix on both arms: the reference generates the 8-decision
trajectory under the frozen deterministic rule; the candidate is
teacher-forced at every decision against the exact reference prefix; the
candidate's actual full-vocabulary winner for that same row is retained
for semantic adjudication; free-running post-branch tensors are never
calibration or holdout evidence (branch trajectories are labeled
`BRANCHED_*`; branch count/position is diagnostic only — no branch-rate
acceptance threshold exists in v3).

The 15 numerical checkpoint families are unchanged in kind; historical
0/1/3/7 capture positions and reducers remain unless a purely mechanical
capture extension is required to preserve same-input evidence. The semantic
decision layer requires decision evidence at ALL 8 decisions.

## 4. Mandatory full-vocabulary numerical envelopes (unchanged)

## 5. Frozen decision domain: reference-top-1024-with-cutoff-ties/1

For every canonical reference FP32 consumer-logit row `r`:
the 1024th-highest reference logit is the cutoff; `D(r)` = every token with
reference logit >= cutoff (exact cutoff ties all included; `|D(r)|` may
exceed 1024); membership ordering is by token id after set construction;
the full-vocabulary reference winner is in `D(r)` by construction.

K=1024 is a fixed, conservative power-of-two reference-head budget chosen
prospectively; it is NOT derived from the #81 rank-17 observation or any
#81 candidate statistic. Changing K or the rule creates a new methodology
version. The domain is reference-derived only; candidate output never
alters membership. A reference-only decision-domain manifest
(schema `inferswarm.issue86.v3-decision-domain-manifest/1`) binds the
construction identity and per-row membership hashes before heterogeneous
candidate calibration is valid; threshold derivation cross-checks every
calibration decision row against it.

## 6. Supplemental decision-local bound E_D

`decision_local_error = max_{i in D(r)} |candidate_i - reference_i|`;
`case_E_D = max over all 8 decisions`; `statistical_E_D` over the exact 576
statistical cases; `stress_E_D` over the exact committed 8 stress cases;
`E_D = max(statistical_E_D, stress_E_D)` — no rounding, no manual editing,
no empirical safety factor (serialized exact hexadecimal binary64).
`E_D` is supplemental and conjunctive with the 15 envelopes; passing
`E_full` does not imply it. Every acceptance-bearing calibration and
holdout decision must prove `decision_local_error <= E_D` BEFORE any
semantic theorem is invoked, else `DECISION_LOCAL_BOUND_EXCEEDED`.

## 7. Statistical design: 16 simultaneous acceptance-bearing bounds

15 numerical envelope families + the calibration-derived E_D family.
Target marginal population coverage p=0.99 per family; simultaneous
confidence 0.95; Bonferroni alpha per family 0.05/16; distribution-free
maximum-order-statistic tolerance construction
(`ceil(log(alpha_i)/log(p))`) gives minimum n = **574**; the balanced
576-case design (24x24) remains sufficient. Machine-reproducible via
`python3 scripts/issue86_v3_thresholds.py statistical-design --json`.
The independent sampling unit is the case, not the token row:
within-case decision/checkpoint values are reduced conservatively (max)
before the across-case maximum.

## 8. Frozen deterministic argmax/tie-break semantics

`ARGMAX_FIRST_MAX / lowest token-id among exactly equal FP32 maxima`.
Tested synthetically (property test over deterministic pseudo-logits);
recorded in applicability/provenance; both arms must use the same rule. A
later execution implementation must explicitly prove the emitted
decision corresponds to this rule; undocumented backend tie behavior is
insufficient. Exact equality at `m_D = 2E_D` remains unstable absent a
stronger prospective proof.

## 9. Semantic gate order (exact)

For every canonical-prefix decision in calibration and holdout:

1. exact integrity / identity / finite-output prerequisites;
2. mandatory numerical-envelope applicability per the v3 case contract;
3. `decision_local_error <= E_D`, else `DECISION_LOCAL_BOUND_EXCEEDED`;
4. actual candidate full-vocabulary winner `j` in `D(r)`, else
   `DECISION_DOMAIN_ESCAPE`;
5. `m_D = r[a] - r[b_D]`;
6. `m_D > 2E_D` — require `j == a` exactly;
7. `m_D <= 2E_D` — require `j` in `A_ED(r)`;
8. after a first allowed unstable divergence, label `BRANCHED_*`; later
   free-running tensors are diagnostic only.

Implemented verbatim in `scripts/issue86_v3_methodology.py::evaluate_decision`
(order proven by unit test: a row violating both bound and containment
reports the BOUND failure).
